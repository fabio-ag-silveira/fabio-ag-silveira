# Fabio Silveira

Engenheiro de Computação formado pela UFGD, em Dourados-MS. Trabalho com visão computacional para o agro na Agroverita Tecnologia. Antes disso, passei quatro anos cuidando de infraestrutura web e automações na Prime2B.

## Hoje

Na Agroverita eu mantenho modelos de detecção de objetos que estão em produção. As usinas mandam imagens pelo aplicativo, eu reanoto, reorganizo o dataset e faço fine-tuning a partir da versão anterior. A versão nova só entra no lugar da antiga se ganhar em mAP@50, precisão e recall e passar nos testes extras. O que mais pesa é derrubar os falsos positivos, porque é isso que decide se o modelo funciona no campo. Boa parte das imagens tem muitos objetos por quadro, então o pipeline de análise é feito sob medida para isso.

Também cuido do back-end, do DevOps no Azure, do front-end e do app Android.
