# Fabio Silveira

Engenheiro de Computação (UFGD) trabalhando com **visão computacional aplicada ao agro** na Agroverita Tecnologia, além de back-end, DevOps e infraestrutura web.

Trabalho no pipeline inteiro: captura e anotação de imagens, treino, avaliação (mAP, precisão/recall, redução de falsos positivos), deploy (incluindo edge com NVIDIA Jetson + TensorRT) e melhoria contínua com dados de campo.
